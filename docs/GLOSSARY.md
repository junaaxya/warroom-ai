# Glossary

**English** | [Bahasa Indonesia](id/GLOSSARY.md)

**Active project** — project currently targeted by the global Supervisor.

**Alias** — human-friendly project name registered with `warroom add`.

**Bridge** — per-project local service connecting Supervisor and division sessions.

**Cockpit** — tmux view showing Frontend and Backend attach clients side-by-side.

**Coordination** — approval/reservation lifecycle required before shared-path semantic changes.

**Division** — independent engineering role; current defaults are Frontend and Backend.

**Guard** — global OpenCode plugin enforcing project path policy.

**Handoff** — persistent project summary of goal, completed work, issues, decisions, verification, and next action.

**Pinned session** — stable OpenCode session ID stored in project state and reused across restarts.

**Project ID** — unique identifier based on project basename plus canonical-path hash.

**Protected path** — path denied for writes in normal War Room workflows.

**Shared path** — path requiring coordination before semantic changes.

**Supervisor** — ChatGPT-facing control plane for planning, delegation, review, verification, and handoff.
